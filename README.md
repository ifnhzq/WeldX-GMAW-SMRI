# Approach to Welding Process Research Data Using WeldX for Butt Joints of S235 Mild Steel in GMAW Welding

## Overview

This repository contains the source code, simulation notebooks, ASDF files, and documentation for my Final Year Project at Universiti Teknologi MARA (UiTM).

The project demonstrates how the WeldX framework can standardize welding research data while integrating thermal analysis based on the Rosenthal analytical model and Monte Carlo uncertainty analysis.

---

## Objectives

- Develop a standardized welding research dataset using WeldX.
- Model GMAW butt joint welding on S235 mild steel.
- Perform Monte Carlo simulations on welding parameter uncertainty.
- Predict thermal cycles using the Rosenthal moving heat source model.
- Store welding metadata using the ASDF format.
